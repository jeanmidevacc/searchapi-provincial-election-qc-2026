# SearchApi examples

One small script per SearchApi.io engine used in this project (`chatgpt`,
`gemini`, `google_news`, `google_rank_tracking`, `google_trends`,
`google_trends_trending_now`), plus `searchapi_endpoints.md` for reference
notes. Each script needs `SEARCHAPI_API_KEY` set in the environment.

All of them also exist as individual public GitHub gists, embeddable
separately (e.g. one per section of an article), just search GitHub gists
for `jeanmidevacc / searchapi-provincial-election-qc-2026`.
